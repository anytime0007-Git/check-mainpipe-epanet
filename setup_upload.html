🔐 ตั้งค่าการอัปโหลดผ่านหน้าเว็บ (สำหรับผู้ดูแลเท่านั้น) v2.1

เปิดไฟล์นี้ในเครื่องของคุณ อย่าอัปโหลดขึ้น GitHub หน้านี้เข้ารหัส token ด้วยรหัสผ่านกลางของทีม แล้วสร้างไฟล์ upload_config.json ให้นำไปวางใน repo ข้างๆ upload.html ทุกขั้นตอนทำงานในเบราว์เซอร์ ไม่มีการส่ง token ไปที่อื่นนอกจาก api.github.com

ขั้นที่ 1 สร้าง token ที่ GitHub

  1. เข้า GitHub → รูปโปรไฟล์ → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access เลือก Only select repositories แล้วเลือกเฉพาะ repo นี้
  3. Permissions → Repository permissions → Contents: Read and write (อย่างอื่นไม่ต้องเลือก)
  4. ตั้งวันหมดอายุตามต้องการ (สูงสุด 1 ปี) แล้วคัดลอก token ที่ขึ้นต้นด้วย github_pat_

ขั้นที่ 2 กรอกข้อมูล

ไฟล์ที่เข้ารหัสแล้วจะอยู่บนเว็บสาธารณะ ใครโหลดไปลองเดารหัสผ่านได้ จึงควรใช้ประโยคยาวๆ เช่น คำสุ่ม 4-5 คำ ไม่ใช้วันเกิดหรือชื่อหน่วยงาน

ขั้นที่ 3 นำไปวางใน repo

อัปโหลดไฟล์นี้ไปที่ repo เดียวกับ index.html ชื่อต้องเป็น upload_config.json ผู้ upload จะใช้หน้า upload.html พร้อมรหัสผ่านกลาง ถ้าต้องการเปลี่ยนรหัสผ่านหรือ token ให้สร้างไฟล์ใหม่ที่หน้านี้แล้วอัปโหลดทับ
